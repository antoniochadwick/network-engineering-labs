# Network Labs

A collection of troubleshooting and build labs I use to practise real-world network support. Each lab starts with a client ticket, includes a full containerlab topology with faults built in, and ends with a post-incident report showing how I found and fixed the problem.

I started in IT helpdesk, moved into networking and system administration and later taught myself software development. These labs combine both sides: Cisco networking skills, and treating labs like code, with version control and clear documentation.

## Labs

| Lab | Type | Level | Topics |
|---|---|---|---|
| [Ahuriri Physio](troubleshooting_labs/ahuriri_physio/) | Troubleshooting | 2 – Junior | 802.1Q trunking, default routing, NAT/PAT |

## How each lab is organised

- `README.md` – the client ticket and how to run the lab
- `SOLUTION.md` – my troubleshooting write-up (spoilers!)
- `*.clab.yml` and `configs/` – topology and startup configs (with the faults built in)

## Requirements

[containerlab](https://containerlab.dev), Docker, and your own Cisco IOL images
(not included – they are licensed by Cisco).
